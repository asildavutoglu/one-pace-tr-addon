# One Pace Türkçe Altyazı - Stremio Addon

One Pace bölümleri için Türkçe altyazı sunan Stremio addon'u.

## Kurulum

Stremio'yu aç → Addons → arama kutusuna yapıştır:
https://onepacetr.app/manifest.json

Install et, bitti. One Pace bölümlerinde otomatik olarak Türkçe altyazı çıkacak.

## Özellikler

- ✅ 154 bölüm Türkçe altyazı
- ✅ ASS (styled) + SRT formatları
- ✅ PC, Android, Android TV desteği
- ✅ 7/24 çalışır sunucu
